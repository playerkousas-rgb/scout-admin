📜 接收 Apps Script（含旅團登記 + 問題回報 + 意見回饋）
⚠️ 需要你重新部署一次才生效。把下方代碼整段貼到 Google Sheet → 擴充功能 → Apps Script → 儲存 → 部署 →「管理部署」→ 編輯 → 版本選「新版本」→ 部署（網址不變）。
API KEY 由 GS 自己產生：貼上後在編輯器上方選「setupApiKey」→「執行」→ 授權，自動生 Key、存腳本屬性並 E-mail 給你（含一鍵填好連結）。
核心保證：欄位對不上自動加欄、Email 附全部欄位＋原始 JSON 備份，資料不漏。
改動：①旅團號改為可選；②已閱寫回（markRead）；③list 讀取受 API KEY 保護（防個人資料外洩）。
📋 前端旅團登記表單代碼（嵌入旅團 APP）
複製貼入旅團 APP 設定頁。只需旅團名、URL、API KEY（旅團號選填）。網址已預先填好。
🐛 問題回報表單代碼（嵌入各 APP）
複製貼入各 APP 的回報／幫助頁，只需改 SOURCE_APP。姓名與聯絡方式均為選填（可匿名、可留底）。
💬 意見回饋表單代碼（嵌入各 APP）
複製貼入各 APP 的設定／關於頁，同樣只需改 SOURCE_APP。姓名與聯絡方式選填。
⚡ 一行 widget（浮動「回報 · 意見」按鈕）
不想逐個 APP 貼表單，就用一行 <script>（右下角浮動按鈕，同時有 🐛 問題回報＋💬 意見回饋）。貼在 </body> 前即可，APP 完全不需要後端。來源自動帶入網址，要覆蓋才加 data-app="項目名"。
🔗 或者用零改動獨立回報頁 — 一行代碼都不用貼，分享連結 / QR 即可（?app= 後面換成 APP 名）：
https://scout-admin-blue.vercel.app/report.html?app=圖書館
📋 Google Sheet 欄位說明
Script 會在第一次收到資料時自動建立工作表、自動補齊標題欄（舊表會自動在右側補上「姓名」「聯絡方式」欄），無需手動加。
⚠️ 升級提醒：把上方 Apps Script 代碼貼上後要重新部署（管理部署 → 編輯 → 版本：新版本）才會生效。「狀態」欄由前端寫回（審核狀態／已閱），開 Sheet 也能看到。

📖 Scout Admin APP 說明書
🔑 API KEY（保護後台讀取）
後台抓取 Sheet（?action=list）與「已閱」寫回都需要帶 API KEY，防止外人拿到 TICK 裡的姓名／聯絡方式等個人資料。
Key 由 GS 自己產生：Apps Script 貼上最新代碼後，在編輯器上方選「setupApiKey」→ 執行 → 授權，就會自動生一組 Key、存進腳本屬性，並 E-mail 給你（信裡有「一鍵填好」連結，點開就會自動填寫下方這欄）。
未設 Key 時系統照常收單，只是讀取不設防。
