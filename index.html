總投稿
📮 作品投稿（SCOUT APP STORE）
這裡是 SCOUT APP STORE（scoutappstore.vercel.app）送來的投稿紀錄，最新在最頂；資料一律照抄到 Google Sheet「作品投稿」＋ Email 通知，不重寫、不漏單。狀態為唯讀，要去 Sheet 改（如「待審核」→「已上架」），改完按「🔄 同步」即可更新。
📜 接收 Apps Script v2.4（旅團登記＋問題回報＋意見回饋＋作品投稿）
⚠️ 需要你重新部署一次才生效。把下方代碼整段貼到 Google Sheet → 擴充功能 → Apps Script → 儲存 → 部署 →「管理部署」→ 編輯 → 版本選「新版本」→ 部署（網址不變）。
API KEY 由 GS 自己產生：貼上後在編輯器上方選「setupApiKey」→「執行」→ 授權，自動生 Key、存腳本屬性並 E-mail 給你（含一鍵填好連結）。Key 保護的是「讀取／已閱／審核」這類後台動作；任何人提交（旅團登記、問題、回饋、作品投稿）都不需要 Key。
核心保證：欄位對不上自動加欄、Email 附全部欄位＋原始 JSON 備份，資料不漏。
v2.4 改動（統一回報格式 v1）：①來源系統自動正規化（library／scoutlibrary.vercel.app → 圖書館，vsbadge → 專章系統…）；②type 別名／中文／寫錯／沒寫都收得到（自動判斷去問題回報還是意見回饋，絕不漏單）；③工作表與欄位完全不變——支部系統、進度追蹤、旅系統、區系統、專章系統之後上線，這份代碼不用再改，也不用加表加欄。
📋 前端旅團登記表單代碼（嵌入旅團 APP）
複製貼入旅團 APP 設定頁。只需旅團名、URL、API KEY（旅團號選填）。網址已預先填好。
🐛 問題回報表單代碼（嵌入各 APP）
複製貼入各 APP 的回報／幫助頁，只需改 SOURCE_APP。姓名與聯絡方式均為選填（可匿名、可留底）。
💬 意見回饋表單代碼（嵌入各 APP）
複製貼入各 APP 的設定／關於頁，同樣只需改 SOURCE_APP。姓名與聯絡方式選填。
⚡ 一行 widget（浮動「回報 · 意見」按鈕）
不想逐個 APP 貼表單，就用一行 <script>（右下角浮動按鈕，同時有 🐛 問題回報＋💬 意見回饋）。貼在 </body> 前即可，APP 完全不需要後端。來源自動帶入網址，要覆蓋才加 data-app="項目名"。
🔗 或者用零改動獨立回報頁 — 一行代碼都不用貼，分享連結 / QR 即可（?app= 後面換成 APP 名）：
https://scout-admin-blue.vercel.app/report.html?app=圖書館
🧩 各系統一行接入代碼（統一回報格式 v1）
所有系統共用同一格式、同一接收端、同一組 Sheet 欄位，唯一分別只有 data-app（來源系統）。
新系統上線 = 貼下面對應那一行，不用改 Apps Script、不用加工作表、不用改欄位、不用碰 Supabase。
沒登記的來源也照收不誤（後台會顯示 🔹 原樣名稱）；要讓它有正式名稱／圖示，只需在 index.html 的 SOURCE_APPS 加一行。
📋 Google Sheet 欄位說明
Script 會在第一次收到資料時自動建立工作表、自動補齊標題欄（舊表會自動在右側補上「姓名」「聯絡方式」欄），無需手動加。
⚠️ 升級提醒：把上方 Apps Script 代碼貼上後要重新部署（管理部署 → 編輯 → 版本：新版本）才會生效。「狀態」欄由前端寫回（審核狀態／已閱），開 Sheet 也能看到。
